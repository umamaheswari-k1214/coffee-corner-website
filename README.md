# ☕ Coffee Corner Website

A responsive coffee shop landing page built using HTML and CSS.

## 🚀 Features
- Responsive design
- Fixed navigation bar
- Smooth scrolling
- Hero section
- About section
- Coffee menu cards
- Hover effects on cards
- Footer with contact details
- Mobile responsive layout using media queries

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox
- Media Queries

## 📸 Sections Included
- Home
- About
- Menu
- Contact/Footer

## 🎯 Purpose
This project was built to practice frontend development concepts like:
- responsive layouts
- flexbox
- positioning
- smooth scrolling
- media queries
- hover effects
